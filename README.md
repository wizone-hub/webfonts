# webfonts

위즈원이 관리하는 홈페이지에서 사용하는 웹폰트 모음입니다.
jsDelivr를 통해 제공하며, 각 사이트는 서버에 있는 기존 폰트 경로를 대체 주소로 함께 지정합니다.

## 사용 주소

    https://cdn.jsdelivr.net/gh/wizone-hub/webfonts@1.1/{폴더}/{파일}

반드시 버전(@1.0, @1.1)을 붙여서 사용합니다. 파일을 바꿀 때는 새 버전을 만들고 주소의 버전을 올립니다.
